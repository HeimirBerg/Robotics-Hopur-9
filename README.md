# Read Me

Þetta er forritið sem keyrir Lalla.

Forritið er byggt upp á þremur hæðum.
Neðst er sorce (src) kóði sem er einangraður við einn íhlut eða fyrir gagnaúrvinslu.
Miðan er modular (modules) kóði sem eru stærri tilbúnar einingar fyrir heildar virkni.
Efst er main.py sem er skráin sem lalli mun keyra á og sér aukalega um að slökkva og kveikja á Raspberry.
