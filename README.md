# Lalli Róbot

Þetta er forritið sem keyrir Lalla.

Forritið er byggt upp á þremur hæðum.
Neðst er source (src) kóði sem er einangraður við einn íhlut eða fyrir gagnaúrvinslu.
Miðjan er modular (modules) kóði sem eru stærri tilbúnar einingar fyrir heildar virkni.
Efst er main.py sem er skráin sem Lalli mun keyra á og sér aukalega um að slökkva og kveikja á Raspberry tölvunni.

Skráin _config.py inniheldur fasta o.fl. eins og stöðvunar fjarlægð.  
Skráin .gitignore inniheldur möppur fyrir backup og prufu kóða sem á ekki að setja á GitHub.  
Mappan .vscode eru sjálfvirkar stillingar frá VS Code svo allir séu með stillt á sama Pythorn Environment.
